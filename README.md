# Side-Bird — Directional Trolling Bird

A 7.5-inch directional trolling bird inspired by the Sterling Tackle Side Tracker.  
The bird uses a hydrodynamic side blade to spread lures wide of the boat wake, with a buoyant self-righting body and a tail keel for stability.
